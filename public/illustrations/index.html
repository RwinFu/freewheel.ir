Annotated Illustration اسکیل نصب‌شده

این صفحه یک «برش توضیحی» (cutaway) از فری‌ویل رولری RINGSPANN FGR … R را با اسکیل annotated-illustration نمایش می‌دهد. طراحی طبق بودجه‌ی کانواس 1200×800 — gutters 240 ساخته شده، برچسب‌ها با scripts/layout_callouts.py بدون تداخل جانمایی شده و با check_illustration.py لینت شده است. دانلود SVG · نقشه سایت →

🎯 یک جمله که شکل آموزش می‌دهد

«فری‌ویل رولری در جهت مجاز هرز می‌چرخد و در جهت مخالف با گیرکردن رولر در فضای گوه‌ای قفل می‌کند — بدون برق و فرمان.»

این جمله caption شکل شد؛ هر برچسب فقط اجزایی را نام می‌برد که همان جمله را می‌سازند.

🔍 انتخاب view: برش یک‌چهارمی (Cutaway)

برش انتخاب شد چون خواننده باید هم بیرون و هم داخل را باهم ببیند. لبه‌ی برش با دو خط موازی + هاشور ضخامت نشان می‌دهد که بدنه «ماده» است نه سوراخ. نمای انفجاری برای آموزش مونتاژ بهتر بود ولی این شکل درباره‌ی «چگونگی قفل» است.

📐 بودجه‌ی کانواس

گاترها اول رزرو شدند (۲۴۰px هر طرف). سوژه داخل [260,940]×[88,720] جا گرفت. همین باعث شد هیچ برچسبی روی نقاشی نیفتد — رایج‌ترین شکست فرم‌های annotate.

viewBox 0 0 1200 800
gutters 240 · top 72 · bottom 64

🏷️ لایه‌ی annotation (اسکریپت)

هشت نقطه‌ی anchor → انتخاب گاتر نزدیک‌تر → بسته‌بندی عمودی با isotonic regression (PAVA) → فاصله‌ی امن بین برچسب‌ها → leader تک‌خم با سگمنت افقی ۲۴px. خط‌ها هرگز قطع نمی‌شوند.

python3 layout_callouts.py callouts.json > ann.svg
python3 check_illustration.py figure.svg # 0 error

۸ برچسب — هر کدام یک داستان کوتاه

۱) حلقه بیرونی — پوسته‌ی ثابت که گشتاور را می‌گیرد. ۲) آب‌بند — مانع ورود گردوغبار (مرگ فری‌ویل نساجی). ۳) بلبرینگ — نگه‌داشتن هم‌محوری. ۴) رولر — المان قفل‌کننده (تماس خطی). ۵) قفس — فاصله‌دهی رولرها. ۶) حلقه درونی — روی شفت با خار DIN 6885. ۷) جای خار — تنها سطحی که تلرانسش سرنوشت‌ساز است. ۸) فضای گوه‌ای — جایی که فیزیک اتفاق می‌افتد: هرچه بار بیشتر، گوه محکم‌تر.
