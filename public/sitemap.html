چطور بخوانیم

از بالا (ROOT) به پایین: هر ستون یک شاخه‌ی اصلی از NAV در src/content/site.ts است. باکس‌های سفید = صفحه، باکس نارنجی = priority بالا، باکس سیاه = ROOT/API، خط‌چین = سیستمی (sitemap/robots/OG). رنگ داخل کاتالوگ = دسته‌بندی taxonomy (steel/mint/coral/ocean).

آمار کل

۴۳ مسیر استاتیک در build (SSG)، ۳۸ URL در sitemap.xml (+ 3 API + 2 meta)، ۱۲ سری RINGSPANN، ۷ برند، ۶ کاربرد، ۵ مقاله. منبع حقیقت: src/app/sitemap.ts که هر گروه را از آرایه‌های محتوا می‌سازد؛ اگر slug جدیدی بدون دسته اضافه شود، build خطا می‌دهد.
